## Bewertungsstatus

Die Einträge werden nach ihrem aktuellen Erkenntnisstand gekennzeichnet:

| Status | Bedeutung |
|---|---|
| BELEGT | In einer Referenzquelle gefunden |
| PLAUSIBEL | Technisch nachvollziehbar, aber noch nicht bestätigt |
| PRÜFEN | Muss im laufenden Spiel getestet werden |
| VERALTUNGSRISIKO | Kann versionsabhängig oder veraltet sein |
| NICHT VERFÜGBAR | Bisher nicht nachweisbar |

**Wichtig:** Ein Eintrag in der Referenzquelle bedeutet nicht automatisch,
dass die Funktion im aktuellen Spiel erfolgreich getestet wurde.
